one sentence, up to 200 characters, on the best advice I ever received.

## The line

> My grandfather told me never to make a promise when I was happy or a decision when I was angry, and thirty years on it is still the only rule I have never broken.

(162 characters, one sentence. Also saved in `entry.txt`.)

## Run

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt` and prints it. The program
checks the line is non-empty, a single sentence, and at most 200
characters, then reads the file back to verify it matches.
